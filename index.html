10월 14~16일에 대본 스튜디오 화면 전체를 다듬었어요. 버튼과 안내 글이 너무 많던 곳을 줄였고, 대본을 올리고 영상을 만드는 동안 지금 무슨 일이 일어나는지 보이게 했어요. 화면마다 ‘이전 화면 / 이후 화면’ 탭을 눌러 같은 자리에서 비교하고, 아래 목록에서 무엇이 바뀌었는지 볼 수 있어요.

첫 화면

대본 스튜디오 메뉴를 눌렀을 때
←/→ 키로도 바꿔요
  • 소개 문구 — “위저드와 별개로 움직여요” 같은 내부 말을 빼고 “대본을 올리면 씬·인물·장소로 나누고, 씬마다 영상을 만들어요.”로.
  • 올리는 곳 — 어디를 눌러도 파일 창이 열려요. ‘직접 붙여넣기’와 씬 헤더·OCR 같은 기술 설명을 뺐어요.
  • 뱃지 — 영상이 하나도 없는데 붙던 ‘진행 중’을 없앴어요. 지금 만들고 있을 때 ‘만드는 중’, 모든 씬에 영상이 있을 때 ‘완성’만 붙어요.
  • 카드 — “영상 0/111 통과” 대신 초록 막대 + “영상 2/111”. 검은 막대(완성)도 초록으로 통일했어요. 회차가 여러 개면 회차 수도 보여요.
  • 거르기·정렬 — 한 줄에 섞여 있던 걸 나눴어요. 왼쪽 칩(전체·만드는 중·완성), 오른쪽 정렬(최근에 고친 순·이름순).

대본 올리기

대본 파일을 올린 뒤
←/→ 키로도 바꿔요
  • 이전 — 드롭존 안에서 아이콘만 돌고 “텍스트 PDF는 10초 안쪽, 스캔본은 20~30초”라고 안내했는데, 84쪽짜리는 실제로 3분 50초가 걸렸어요.
  • 이후 — 팝업에서 단계마다 진행을 보여 줘요. 파일 읽기(쪽 수) → 글자 읽기(“52 / 80쪽” 막대) → 씬 나누기(씬·회차 수) → 인물·장소 찾기. 같은 파일이면 “전에 읽어 둔 결과 사용”.
  • 끝나면 — 회차·씬·인물·장소 수를 보여 주고 ‘작품 열기’로 이동해요. 예상 시간은 근거가 없어 쓰지 않아요.
  • 속도 — 84쪽 대본 올리기가 3분 50초에서 약 1분 30초로 줄었어요.

스토리 탭

작품을 열면 처음 보이는 탭
←/→ 키로도 바꿔요
  • 인물부터 — 들어가자마자 인물·장소·사물 카드가 보여요. 같은 크기(세로 사진) 카드로 맞췄어요.
  • 복장 — 인물 카드 아래 동그라미로 겹쳐 보여요. 카드를 누르면 설정·영어 묘사·복장을 고쳐요.
  • 얼굴 등록 — ‘자산 등록’ 버튼, ‘ModelArk 자산 2/50’ 표시, 자산 ID 직접 입력을 없앴어요. 영상을 만들 때 초상으로 알아서 연결돼요.
  • 대본 이어붙이기·작품 정보 — 위 칸을 차지하던 것을 오른쪽 위 ‘＋ 대본 추가’와 작품 이름 옆 ⓘ로 옮겼어요.
  • 상단 버튼 — 탭 줄 오른쪽 ‘이 회차 생성 / 이 회차 내보내기’를 생성 탭 아래 바로 모았어요.

대본 탭

씬을 고르고 대본을 고치는 곳
←/→ 키로도 바꿔요
  • 씬 머리 — 입력칸 7개(번호·제목·초 ±·엑스트라 ±·상태·모드)가 한 줄에 몰려 있던 것을 제목 + 칩 한 줄로. 칩(15초·엑스트라)을 누르면 작은 창에서 바꿔요.
  • 등장 — 오른쪽 ‘이 씬 참조’ 칸을 대본 바로 위 한 줄로 올렸어요. 인물을 누르면 그 씬에서 입을 옷, 장소를 누르면 장소를 그 자리에서 골라요.
  • 버튼 — 아래 버튼 줄(나누기·합치기·미리보기·프롬프트·만들기)을 오른쪽 위 ‘영상 만들기’ 하나와 ⋯ 메뉴로. 미리보기는 쓰지 않아 뺐어요.
  • 이 씬 영상 — 오른쪽 빈 공간에 그 씬의 영상이 나와요. 대본을 고치며 결과를 바로 비교할 수 있어요.
  • 확인할 것 — 큰 경고 상자 대신 “확인할 것 2개 · 대사가 너무 길어요 …” 한 줄. ‘보기’로 펼쳐요.
  • 씬 목록 — 찾기 칸, 상태는 글자 대신 아이콘(✓ 완성·돌아가는 화살표 만드는 중·! 실패), ‘＋ 씬 추가’는 목록 맨 아래.
  • 속도 — 씬을 누를 때마다 서버에 다녀오던 것을 작품을 열 때 한 번에 받아 둬서, 씬을 바꿀 때 기다리지 않아요.

생성 탭

씬 영상을 만들고 확인하는 곳
←/→ 키로도 바꿔요
  • 도구 줄 — “2씬 중 완성 2 · 반려 0 · 생성 중 0 · 초안 0” 문장과 거르기가 섞여 있던 것을 진행 막대 + 거르기 칩(전체·완성·만들기 전·실패) 하나로.
  • 버튼은 아래 바 — 만들기·전부 받기·에디터로를 화면 아래 바에 모았어요. 카드를 고르면 검은 바로 바뀌어 고른 것만 다시 만들기·받기·에디터로 보내기.
  • 만드는 중 카드 — 처음 만들 때와 다시 만들 때 모두 어두운 화면 + 점 세 개, 서버가 아는 단계만(대기 중 → 인물 등록 → 만드는 중 · 14:02 시작 → 영상 받는 중). 얼굴이 연결된 인물은 동그라미로.
  • AI 검수 없앰 — ‘반려’ 대신 ‘실패’는 실제로 못 만든 경우에만.

←/→ 키로도 바꿔요
이전에는 바뀐 점을 알려 주는 화면이 없었어요.
팝업은 아이디마다 처음 한 번만 떠서 팝업 자체는 다시 띄워 찍지 못했어요. 위 화면들이 팝업 안에 그림으로 들어가요.
  • 탭마다 그 탭에서 바뀐 것만 실제 화면 캡처와 함께 2~3장 팝업으로 보여 줘요. 아이디마다 한 번만 뜨고, 다른 컴퓨터에서도 다시 뜨지 않아요.
  • 스토리: 인물 카드·ⓘ 작품 정보 / 대본: 등장·키보드·대본 옆 영상 / 생성: 아래 바·카드 고르기·모든 회차 만들기.
